# Adaptive-Graph-Encoding-Optimization-for-Large-Language-Models
Final Project for DATS-SHU 369: Machine Learning with Graphs, supervised by Prof. Qiaoyu Tan  
## Task:  
Reproduced and optimized the ICML-nominated paper 'Large Language and Graph Assistant'  
Improved graph feature extraction using a Random Walk-based template and a multi-head self-attention projector.This boosted PubMed node classification accuracy to 94.83% and quadrupled the speed of large graph tasks.
